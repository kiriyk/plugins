# AI Picks 0.5.0: проверка моделей этапов

Проверено 7 ноября 2026. Основная модель для сравнения: `openai/gpt-4.1-mini`. Это фиксированный baseline измерения, настройка модели пользователя не меняется.

## Что реализовано

- Независимые роли Extract/Jev с общим ключом RouterAI; исходно обе `primary`.
- Extract: один пакет веб-фрагментов, проверка точных позиций UTF-16/code points, источники и окружение назначает код; TMDB подтверждает карточки.
- Jev: закрытый и проверенный пул, полная упаковка до HTTP, отдельный бюджет до четырёх запросов, общий дедлайн, обычный отбор всего пула при неполной оценке.
- Выбранные Jev ID и порядок фиксирует код; ошибка объяснения не удаляет фильм.
- Явная проверка выбранных ролей из обоих меню, до двух запросов RouterAI и без Tavily; настройки отменяют активный поиск.

## Проверки

- `npm test`: 235 тестов, без ошибок. Включены текущий основной режим, веб-поиск, обе роли по отдельности и вместе, минимум бюджета, 10/20/all, отмена, неполные ответы, полный fallback и фиксированные объяснения.
- `npm run check`: ES5 и синтаксис JS пройдены.
- `git diff --check`: без ошибок.
- Контракты отдельно проверены живыми синтетическими вызовами RouterAI; сохранены обезличенные ответы. Extract принимает `provider.options.scaledown.entities` и вернул codepoint offsets после emoji. Jev вернула Choice/probabilities/confidence и фактическую версию `typesafe/jev-1.14-20261014`.

## Сравнение на фиксированной выборке

Для каждого этапа размечено 20 синтетических случаев: 10 development и 10 holdout. Разметка закоммичена до вызовов. Выполнено по 20 запросов основной и специализированной модели для каждого этапа, всего 80; дополнительно две первичные проверки контракта. Tavily/TMDB в этих измерениях не вызываются.

Полный запуск основной модели после fallback в сравнении не выполнялся; он проверен отдельно сценариями контроллера.

Результаты development/holdout, токены, returned usage и реальные версии доступны в `node scripts/compare-extract.cjs` / `node scripts/compare-ranking.cjs`. Стоимость Jev не возвращается в usage; экономия по прайс-листу не заявляется. Вероятности не калиброваны на предпочтения пользователя.

## Результат ревью и границы

Независимое ревью не выявило критических проблем. Два важных замечания исправлены и покрыты тестами RED→GREEN: повреждённые непустые сущности Extract теперь дают ошибку контракта; дополнительные источники требуют целого упоминания, поэтому `It` не считается упомянутым в `Italy`. Замечание о порядке переоценено как важное из-за лимитов: названия сортируются по первому месту в исходном тексте до ограничения двадцатью.

API-контракты подтверждены, но статистического превосходства на реальных запросах эта выборка не доказывает. Качество живого TMDB-сопоставления, физический Android TV и полный поиск из реальных пользовательских фраз не проверены этим отчётом. Автоматические сценарии проверяют их программные границы. Ревьюер воспроизвёл offline-проверки, но не повторял оплачиваемые API-вызовы. Обе роли остаются включаемыми вручную; условия для включения по умолчанию не считаются выполненными.

Исполнение проверок ролей и общий интерфейс сравнения объединены между этапами Extract/Jev; сбор и фиксированные объяснения интегрированы вместе, чтобы не выпускать промежуточный незавершённый пайплайн. Перенос в KADR Sync и публикация в основной ветке в этот этап не входят.
