# Совместимость

Целевой контракт: Lampa 3.3.8, yumata/lampa-source commit 71733ed81f4b13ac1ed1b3328cbbaa7e01afdbd2.

Используются отдельные Reguest.native с attempts=0/cache=false. clear() подавляет callbacks, но физическая отмена HTTP не гарантируется. TMDB.api/key берутся из Lampa без копирования ключей.

| Среда | Реальный RouterAI tool-вызов | Каталог/карточки/навигация |
| --- | --- | --- |
| Браузер, origin самой Lampa | NOT RUN — нет локально введённого ключа | NOT RUN |
| Android TV, native transport | NOT RUN — устройство не подключено | NOT RUN |
| Tizen/webOS, дополнительная цель | NOT RUN | NOT RUN |

Ранняя проба: в самой Lampa локально ввести ключ и ID текстовой модели с tools; отправить JSON POST к https://routerai.ru/api/v1/chat/completions с Bearer и forced function connection_check({ok:true}). Успехом считается именно ожидаемый tool call, а не обычный текст. Проверка выполняет платный запрос. Не выводить ключ/заголовки/тело запроса в консоль или отчёт. После появления настроек плагина эту пробу выполняет «Проверить подключение».

Проверять запрос с origin приложения; curl и DOM-тесты не подтверждают CORS. Результаты записывать без ключей с версией приложения/браузера, моделью и датой. При отсутствии устройства/ключа продолжать офлайн-разработку, оставляя NOT RUN до реальной проверки.
