## Как выполнить ручную приёмку

1. Установить JS в настоящую Lampa. Записать версию Manifest и браузера/Android-приложения без личных данных.
2. Локально ввести ключ RouterAI, выбрать модель и записать только её ID. Ключ не публиковать в отчёте, чате или репозитории.
3. Нажать «Проверить подключение». Успех означает ожидаемый tool call. Проверка платная; список моделей сам по себе не подтверждает совместимость.
4. Выполнить пять запросов из таблицы. Проверить карточки, длительность и жанры в каталоге, объяснения без спойлеров, отсутствие повторов и сохранение условий при уточнении.
5. Во время запроса нажать отмену, затем изменить ключ/модель или запустить другой запрос. Поздний ответ не должен менять экран.
6. Открыть карточку и вернуться, открыть «Почему предложен» и закрыть. Проверить возврат фокуса с клавиатуры и пульта.
7. Для браузера проверять запросы с origin самой Lampa; curl и локальный тестовый стенд не заменяют эту проверку.
8. Записать PASS/FAIL, версию, модель, дату и краткую причину. При FAIL сохранить описание ошибки без заголовков авторизации и запросов с ключом.

До выполнения этих проверок подтверждённой готовности Android TV и реального RouterAI нет. Исходники, сборка и автоматическая приёмка завершены отдельно от проверки на устройстве.


## Итоговое ревью

Независимое ревью всей ветки выполнено после задач 1–9. Критических замечаний и отложенных мелких замечаний нет. Два существенных дефекта воспроизведены падающими тестами и исправлены:

- Фокус карточек и кнопок результатов теперь вызывает Scroll.update и сохраняется при возврате из полной карточки или объяснения.
- В formFilters передаются только заполненные поля жанров: выбранная в форме «Драма» сочетается с текстовым «без ужасов».

Регрессионные проверки RED → GREEN; полный набор после исправлений: 88/88. DOM harness теперь воспроизводит нативную отправку hover:focus из Controller.collectionFocus и callback Card.onFocus.

Сомнение о window.Navigator снято по закреплённым исходникам: public/vender/navigator/navigator.js создаёт глобальный SpatialNavigator. Поддержка произвольной страницы без runtime Lampa не заявлена.

Решения реализации и ограничения ревью:

- session.setIntent сохраняет показанные ID при уточнении, а словари передаются в buildMessages, чтобы модель видела настоящие ID жанров. Цена ошибки: непоследовательное уточнение; покрыто тестами session/controller/prompts.
- Настоящий RouterAI и CORS из origin самой Lampa оставлены NOT RUN до ключа и целевой среды. Цена ошибки: сетевые ошибки на устройстве.
- Физические Android TV, Tizen/webOS оставлены NOT RUN до доступа к устройствам. Цена ошибки: несовместимость навигации или транспорта платформы.
- Качество рекомендаций и отсутствие смысловых спойлеров не подтверждаются имитацией модели. Цена ошибки: неподходящая рекомендация или спойлер; требуется ручная приёмка с выбранной моделью.
- Отмена подавляет поздние callbacks, физический HTTP abort не обещается. Цена ограничения: уже отправленный запрос может завершиться и тарифицироваться.

Живой тест прямого api.themoviedb.org из среды разработки был предпринят: каталог недоступен через текущую сеть (ECONNREFUSED напрямую, HTTP CONNECT 502 через сетевой прокси). Этот результат не является проверкой успешного поиска.
