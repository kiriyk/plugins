# Проверка доработок 0.2.0

Дата: 2026-10-23. Ветка: fix/ai-picks-controls. Реальная Lampa на телевизоре и оплачиваемый RouterAI-запрос в этой проверке не запускались.

## Исправления и функции

- Исправлена высота окна поиска: Scroll.minus плюс явная высота доступной области в пикселях, пересчёт при resize и возврате в активность.
- Окна объяснения и уточнения получают jQuery-контейнер с безопасным текстом. DOM-расширение Lampa Element.find возвращает одиночный элемент или null, поэтому передача обычного DOM в Modal.bind приводила к ошибке чтения on у null.
- Модели фильтруются по названию/ID без повторной загрузки каталога; ручной ввод остаётся.
- В настройках приложения доступны ключ, модель, проверка, лимиты, тайм-ауты, число карточек и диагностика.
- Журнал показывает реальные параметры каталога, временные затраты, область тайм-аута и причины отказа по карточкам. Добавлены просмотр с пульта, копирование, скачивание и вход в консоль Lampa.

## Автоматическая проверка

Node: 111/111. npm test пересобирает артефакт. ES5 Acorn и node --check проходят.

Тесты покрывают значения по умолчанию и повреждённые настройки; применение изменённых ограничений в реальном контроллере; поиск модели/ручной ввод; контракт Modal; размер viewport и resize; сроки запросов и общий срок; журнал с настоящим транспортом; исключение секретов; ограничение размера, очистку, чтение и ошибку локального хранилища.

## Браузерное воспроизведение

Chrome 155, 1280×720. В стенд загружены исходные Scroll, Layer, Modal, Define и jQuery из yumata/lampa-source; окружение каталога/активности заменено локальными контрактами. Встроенный браузер Codex недоступен из-за ошибки подключения, использован отдельный локальный Chrome.

До исправления окно скролла заканчивалось на y=1631 при высоте экрана 720, нижняя кнопка находилась на y=1468; body не сдвигался. Открытие объяснения на неполном DOM-контракте падало, а с DOM-расширениями Lampa тот же вызов возвращает null из find.

После исправления viewport имеет высоту 650 при верхней панели 70 и заканчивается на y=720; нижняя кнопка видна на y=557–605; Scroll применяет translate3d(0px,-911px,0px). Окно содержит настоящий текст объяснения без ошибок JavaScript. После resize до 1280×900 viewport заканчивается на y=900, нижняя кнопка — на y=785.

Длинный журнал в настоящем Modal прокручивается кнопками вверх/вниз: позиция изменяется с 0 на -108. Он не содержит единственную кнопку выбора, которая перехватывала бы стрелки вместо прокрутки текста. «Назад» закрывает окно.

## Что ещё проверить на устройстве

Обновить JS до 0.2.0, перезапустить Lampa и проверить прокрутку с настоящим пультом, открытие объяснения, выбор модели и журнал. Новые лимиты не подтверждают устранение прежних сетевых тайм-аутов TMDB: [отчёт живой проверки](tmdb-live-check.md). Для нового тайм-аута включить журнал и сохранить JSON по [инструкции](diagnostics.md).
