# Живая проверка TMDB

Дата: 2026-10-23. Проверка выполнена после явного разрешения использовать штатный прокси Lampa https://apitmdb.cub.best/3/.

Исполнялся настоящий src/catalog.js и локальная валидация src/domain.js. TMDB.api/key подставлены по закреплённым исходникам Lampa 3.3.8; HTTP выполнял curl из среды разработки. Ответы каталога настоящие. Использован только публичный встроенный ключ TMDB; его значение не сохранено в отчёте или исходниках плагина. RouterAI не вызывался.

Это проверка адаптера с настоящим каталогом. Она не проверяет Reguest.native на Android, интерфейс настоящей Lampa или CORS из её origin.

Последний фильтрованный запрос: включить драму (18), исключить ужасы (27), 2000–2025 годы, страна производства US, до 120 минут. Тайм-аут составил 10065 мс. Отдельный диагностический запуск с 25 секундами также не завершился; тайм-ауты самого плагина не увеличивались.

Минимальные контрольные URL discovery/movie, recommendations и similar без полного набора параметров возвращали результаты. Некоторые комбинации языка и параметров отвечали, другие завершались тайм-аутом. Это не доказывает единую причину сбоя. Работа комбинированного подбора через данный маршрут остаётся открытой проверкой.

Прямое обращение к api.themoviedb.org из текущей среды тоже не прошло: сетевой CONNECT 502/curl 56. Оно не даёт независимого подтверждения фильтрованного discovery.

## Исправление по итогам проверки

Плагин задавал ru-RU и игнорировал штатную настройку каталога. Теперь он читает текущий Lampa.Storage.field('tmdb_lang'), как источник TMDB самой Lampa; резервное значение — ru. Явный options.language для интеграций сохраняет приоритет.

Регрессионный тест сначала воспроизвёл ошибку, затем прошёл после исправления. Финальные поиск фильма и сериала проверены уже исправленным адаптером с настройкой ru. Полный автоматический набор: 89/89; ES5 и синтаксис проходят.

Языковое исправление не считается доказанным устранением всех сетевых тайм-аутов. Полную готовность поиска по фильтрам, настоящей Lampa и Android TV этот отчёт не подтверждает.
