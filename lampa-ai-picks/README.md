# ИИ-подборки для Lampa

Плагин подбирает фильмы и сериалы по описанию, фильтрам и фильмам-примерам. ИИ через RouterAI управляет поиском в TMDB, а Lampa показывает найденные карточки с короткими объяснениями.

Версия 0.4.1; [проверка рейтингов и счётчика](docs/rating-filter-check.md). Контракты интеграции проверены по исходникам Lampa 3.3.8. Основные целевые среды — Android TV и браузер. Реальный вызов RouterAI и работу на физическом Android TV ещё необходимо проверить: текущие результаты приведены в [приёмке](docs/acceptance.md). Живой поиск TMDB проверен частично: поиск названий работает, discovery фильмов по фильтрам завершался тайм-аутом; [отчёт](docs/tmdb-live-check.md).

## Установка

1. Разместите файл **ai-picks.js** на доступном устройству HTTPS-хостинге. Для запуска нужен только этот файл; исходники и npm на устройстве не нужны.
2. В Lampa откройте «Настройки → Расширения → Добавить плагин» и укажите полный URL файла, например https://ВАШ-ХОСТ/lampa-ai-picks/ai-picks.js.
3. Полностью перезапустите Lampa. В меню появятся «ИИ-подборки».
4. Откройте раздел и «Настройки ИИ». Введите личный API key RouterAI и выберите текстовую модель с поддержкой инструментов. Если список не загрузился, используйте «Ввести ID модели».
5. Нажмите «Проверить подключение». Проверка выполняет короткий платный запрос к выбранной модели и требует от неё настоящий вызов инструмента.

Плагин использует встроенный адрес RouterAI https://routerai.ru/api/v1. Собственный сервер не требуется. Ключ сохраняется в настройках этого устройства; в JavaScript его вставлять не нужно. Ключ не включается в промпт и собственные журналы плагина. Ключ TMDB и способ доступа к каталогу берутся из Lampa.

[Начало работы с RouterAI](https://routerai.ru/docs/guides/overview/quickstart).

## Как пользоваться

Можно написать только текст, задать только фильтры или выбрать фильм-пример. Например:

> Похожее на «Остров проклятых», без ужасов, до двух часов.

«Добавить условия» открывает формат, жанры с включением/исключением, годы, страны производства и максимальную длительность. Для сериалов длительность означает длительность серии. Источник рейтинга выбирается отдельно: **IMDb** (по умолчанию), **Кинопоиск** или **TMDB**. Порог «Рейтинг от» принимает дробные значения, например 7,5; пустое поле отключает проверку рейтинга. Условия можно задать и текстом: «детектив с IMDb от 7,5». Если источник в тексте не назван, используется IMDb. Явные фильтры формы обязательны. Можно добавить до трёх примеров из поиска каталога. Выбранный пример удаляется кнопкой с его названием.

В «Настройки ИИ → Показывать фильмов» доступны **10 / 20 / Без лимита**. После «Подобрать» появятся отобранные карточки в пределах этого значения (по умолчанию до 10). «Без лимита» показывает все отобранные фильмы завершённого поиска: пул ограничен 80 кандидатами, бюджетами времени и запросов. Большая подборка раскрывается по 20 кнопкой «Показать следующие», без новых запросов к ИИ или каталогу. Выбор карточки открывает обычную страницу Lampa; «Почему предложен» открывает объяснение, доступное с пульта и клавиатуры. Распознанные условия показываются над результатами.

- «Ещё варианты» ищет следующую порцию и исключает все ранее предложенные в текущей сессии карточки, включая ещё не раскрытые страницы предыдущей подборки.
- «Уточнить» меняет пожелание, сохраняя остальные условия. Предыдущая подборка остаётся до получения нового результата.
- «Отменить поиск» прекращает обработку результата. Уже отправленный HTTP-запрос не всегда можно физически остановить.
- При противоречии текста и фильтров плагин предлагает вернуться к запросу. При неоднозначном названии примера предлагает выбрать карточку.

Включённые жанры и страны трактуются как «любой из выбранных», исключённые жанры — как запрет каждого. Если обязательную длительность, страну или другое условие нельзя подтвердить, карточка не проходит проверку. Условия автоматически не ослабляются. Отсутствие жанра «ужасы» не гарантирует отсутствия пугающих сцен.

## Поиск в интернете

1. В «Настройки ИИ → Ключ Tavily» введите личный ключ бесплатного аккаунта.
2. Нажмите «Проверить интернет-поиск». Это настоящий запрос Tavily basic, расходующий один кредит; он выполняется только по нажатию.
3. На экране подбора включите **«Поиск в интернете»** и задайте пожелание, фильтры или фильмы-примеры.

Сначала ИИ формирует до двух веб-запросов. Tavily возвращает до десяти страниц на запрос; ИИ извлекает названия, плагин однозначно сопоставляет их с TMDB и проверяет все обычные фильтры и рейтинг. Затем поиск может дополняться стандартными инструментами TMDB. Страна производства и год выпуска проверяются по каталогу, а не по географии поиска или дате статьи. При нескольких совпадениях названия или неполной выдаче каталогового поиска кандидат пропускается.

«Почему предложен» включает названия и домены веб-источников обычным текстом. Карточки без подтверждения TMDB не создаются. Ссылки не открываются автоматически. При выключенном режиме запросов Tavily и отдельного разбора веб-страниц через ИИ нет.

Используется только Tavily basic: без crawl, extract, advanced и автоматических повторов. На бесплатном тарифе Tavily есть 1000 кредитов в месяц; basic расходует один кредит за запрос ([тариф](https://www.tavily.com/pricing), [учёт кредитов](https://docs.tavily.com/documentation/api-credits); проверено 2026-11-02). Оставьте платный режим/автопополнение аккаунта выключенными. Внешний веб-поиск может быть бесплатным в рамках квоты; обращения к выбранной модели RouterAI учитываются отдельно, включая один дополнительный разбор найденных названий.

Ответы кэшируются на 24 часа, до 20 запросов и 512 КиБ; «Ещё варианты» повторно использует веб-контекст в пределах TTL, исключая предложенные карточки. На устройство и ключ установлен дополнительный предел 950 отправок за календарный месяц UTC. В настройках видно «Учтено на этом устройстве»; это локальный счётчик, а не остаток аккаунта: другие устройства/клиенты и новые ключи того же аккаунта ему неизвестны. Тайм-аут учитывается консервативно как возможный расход кредита. При недоступном хранилище кэш и счётчик живут только в памяти.

При квоте, ошибке доступа или сети плагин сообщает причину и продолжает обычный подбор TMDB. Отмена останавливает текущий поиск целиком. Для метаданных и рейтингов сохраняется резерв общего HTTP-бюджета, поэтому число сопоставленных веб-названий может быть меньше двадцати.

Ключ пока хранится на этом устройстве; общего сервера в этом этапе нет. Прямой аутентифицированный запрос Tavily и качество на реальном ТВ ещё не проверены. Сначала выполните проверку подключения на своём устройстве: доступность и CORS могут зависеть от среды. Перенос ключа, общего кэша и квоты в KADR Sync — следующий отдельный этап.

## Счётчик проверки

Во время поиска и после него виден счётчик «Проверено кандидатов: X из Y». Y — уникальные полученные кандидаты текущего запуска, без фильмов-примеров и уже показанных вариантов. X — кандидаты, для которых проверка дала определённый результат: соответствие, несоответствие обычным условиям или известный рейтинг выше/ниже порога. Ошибки запросов и отсутствие обязательных данных не считаются завершённой проверкой.

«Прошли условия» — подошли по году, жанрам, стране и длительности; «Прошли рейтинг» — дополнительно прошли порог выбранного источника; «Выбрано» — вошли в итоговую подборку. Это этапы отбора, а не утверждение, что ИИ подробно изучил каждый фильм. Все доступные кандидаты проходят проверку кодом до следующего выбора ИИ; повторы не увеличивают счётчик.

После ответа модели видны «Доступно ИИ» — число кандидатов после всех проверок — и «Предложений ИИ» — суммарное число предложений в ответах модели, включая повторы и некорректные варианты. «Отклонено по смыслу» и «Недостаточно данных ИИ» учитывают только явные решения модели по известным кандидатам. «Отклонено проверкой ответа» — предложения с неизвестным ключом, нарушением условий или некорректным объяснением. Пропуск кандидата в ответе не считается смысловым отказом: если подборка не заполнена, такие кандидаты показываются как «Без решения ИИ».

Если модель вернула меньше запрошенного количества и остались кандидаты без решения, плагин выполняет не более одного дополнительного отбора в пределах общего бюджета обращений к ИИ и времени. ИИ получает уже выбранные ключи и оставшихся кандидатов; новые запросы к Tavily и каталогу на этом этапе не выполняются. Первые проверенные варианты сохраняются, новые проходят те же проверки. При ошибке, тайм-ауте или исчерпании бюджета остаётся проверенная частичная подборка с пояснением. Если по всем оставшимся кандидатам есть явный отказ, дополнительного отбора нет. Количество не добивается неподходящими фильмами.

Нет рейтинга, ошибки рейтингов, ошибки/отсутствие метаданных и непроверенные кандидаты показываются отдельно. Если время или HTTP-квота закончились, счётчик показывает неполную проверку и причину. Условия автоматически не ослабляются, непроверенные фильмы в результат не попадают.

### Откуда берётся рейтинг

- **IMDb:** [Agregarr](https://agregarr.org/docs/imdb-ratings/) — публичный бесплатный API без ключа, пакетная проверка точных IMDb ID. ID получаем из TMDB через действующую конфигурацию Lampa. Это сторонний сервис на базе ежедневных некоммерческих наборов IMDb, без обещания неограниченной доступности.
- **Кинопоиск:** Kinopoisk API Unofficial, ключ задаётся в «Настройки ИИ → Ключ API Кинопоиска». Ключ общий с плагином рейтингов на постерах. Сначала точные ID, при их отсутствии — строгий однозначный поиск по названию, году и типу. Каждое обращение, включая поиск, расходует квоту КП. По умолчанию допускается до 10 запросов КП за запуск; предел настраивается. При HTTP 401/402/403/429 новые запросы КП этого запуска прекращаются.
- **TMDB:** собственный `vote_average` каталога; внешние сервисы рейтингов не запрашиваются.

Рейтинг проверяется только у кандидатов, прошедших остальные условия. Источники не подменяются. Без заданного порога запросов рейтинга от ИИ-плагина нет; установленный отдельно плагин рейтингов продолжает работать по своим настройкам. Успешные ответы IMDb/КП кэшируются на 24 часа, отсутствие оценки — на 12 часов; сетевые ошибки не кэшируются. Запросы рейтингов входят в общий HTTP-бюджет поиска.

## Настройки

«Настройки → ИИ-подборки» содержит прямые пункты подключения, числовых лимитов и диагностики. Они также доступны из «Настройки ИИ» на экране подбора.

В выборе модели пункт «Найти модель» фильтрует загруженный список по названию и ID без учёта регистра. Ручной ввод ID доступен и при ошибке загрузки.

| Параметр | По умолчанию | Диапазон |
| --- | --- | --- |
| Шагов ИИ, включая итоговый ответ | 5 | 3–12 |
| Действий ИИ в каталоге | 12 | 4–48 |
| Запросов рейтинга КП за поиск | 10 | 1–80 |
| HTTP-запросов к каталогу | 40 | 10–120 |
| Ожидание ответа ИИ | 25 с | 5–120 с |
| Ожидание каталога | 10 с | 3–60 с |
| Время всего поиска | 90 с | 30–600 с |
| Показывать фильмов | 10 | 10 / 20 / Без лимита |

Последний шаг резервируется для итогового ответа. Тайм-аут отдельного запроса ограничен остатком общего времени. Увеличение шагов может увеличить стоимость; сетевые ошибки не повторяются автоматически. Исправление некорректного или обрезанного ответа ИИ учитывается в том же бюджете шагов. Изменение параметров останавливает текущий поиск, новые значения используются при следующем запуске.

## Как получить логи

Откройте «Диагностика и журнал», включите диагностику, повторите проблемный поиск и выберите «Показать журнал», «Скопировать журнал» или «Скачать журнал JSON». На телевизоре журнал прокручивается стрелками, закрывается кнопкой «Назад». Записи также видны под меткой AIPicks в консоли Lampa.

Журнал показывает распознанные фильтры, параметры запросов, время ответа и фактическую причину исключения карточки. Отдельно отмечает тайм-аут каталога, ИИ и всего поиска. API-ключи, email, полные URL и тексты запросов/ответов в журнал не попадают. [Подробная инструкция](docs/diagnostics.md).

## Как устроен поиск

Модель может нормализовать намерение, искать названия, находить ключевые слова, запрашивать подбор по фильтрам, рекомендации к известным фильмам и подробности карточек. Все каталожные запросы выполняет плагин. Модель не может подставить произвольный URL или выдуманный ID в готовую подборку.

Поиск ограничен кандидатами, которые удалось получить. Это не полный семантический индекс каталога. Настроение и сюжетное сходство оценивает ИИ; фактические ограничения повторно проверяются в коде. Объяснениям задаётся запрет на спойлеры, но абсолютная безошибочность модели не гарантируется.

Лимиты одного запуска по умолчанию: 5 обращений к ИИ, 12 инструментов, 80 кандидатов, 40 запросов к каталогу, 3 одновременных запроса к каталогу/веб-поиску и 90 секунд. На разбор запроса выделяется до 2048 токенов ответа; на извлечение веб-названий — до 4096. Для выбора результатов — до 4096 / 8192 / 16384 токенов соответственно режимам 10 / 20 / Без лимита. Это верхние границы, фактический расход зависит от модели и ответа. Если модель отклоняет большой ответ, выберите другую модель или меньшую выдачу. При обрезанном ответе разрешена одна попытка исправления в общем бюджете; неполный ответ не публикуется. Сетевые ошибки не повторяются автоматически, модель скрыто не заменяется.

Сессия хранится в памяти до перезагрузки, максимум 200 предложенных карточек. История просмотров и персональные оценки в первой версии не используются. Отдельный плагин истории будет подключён позднее.

## Если что-то не работает

- Нет пункта меню: проверьте URL JS, включение расширения, перезапуск и наличие стандартного API Lampa 3.x.
- Ошибка ключа или доступа: проверьте ключ RouterAI и доступ к модели. При недостатке средств пополните баланс в RouterAI.
- Ограничение частоты: повторите позже. Плагин не отправляет платный запрос автоматически заново.
- Модель не выполнила инструмент: выберите другую текстовую модель с поддержкой tools и повторите проверку подключения.
- Сетевая ошибка: проверьте доступ к RouterAI и TMDB именно на устройстве с Lampa. Настройки прокси TMDB не применяются к RouterAI. Сторонний CORS-прокси в плагин не включён.
- Мало результатов: попробуйте другой запрос или ослабьте ограничения самостоятельно. Карточки без нужных метаданных исключаются.
- Для формата «Всё» жанры фильмов и сериалов имеют разные словари. Уточните ограничения для обоих типов или выберите один формат.
- После обновления загружается старый JS: измените URL на .../ai-picks.js?v=2 и перезапустите Lampa.

## Разработка и проверки

Нужен Node.js 20+. Из каталога плагина:

~~~sh
npm ci
npm test
npm run check
~~~

npm test сначала собирает ai-picks.js, затем выполняет node:test с имитацией внешних API. npm run check проверяет синтаксис Acorn в режиме ES5 и node --check. npm run build отдельно пересобирает устанавливаемый файл. В runtime нет сторонних npm-зависимостей.
