# Sled — история и продолжение просмотра для KADR

Плагин Lampa для связки с плеером KADR и сервером истории `kadr-sync-server`.

- При запуске фильма или серии во внешнем плеере Android спрашивает «Продолжить с 25:40 / Сначала» (если сохранено больше 10 секунд) и передаёт KADR позицию с откатом на 10 секунд.
- Регистрирует просмотр на сервере; KADR сам отправляет прогресс раз в минуту, при паузе и выходе.
- Если в KADR нажата «Следующая серия», после возврата запускает следующую серию из того же источника и озвучки. Если сервер недоступен — спрашивает.
- Хранит историю профиля локально и синхронизирует её с сервером. Перед каждым запуском подтягивает свежие позиции, но ждёт сервер не дольше 2,5 секунды.
- Синхронизируется сам: раз в минуту, при возвращении в Lampa и при показе главного экрана. Перезапуск не нужен.
- После каждой синхронизации переносит позиции с сервера в таймлайн Lampa: онлайн-плагины (Showy, Online Mod) сразу показывают серверные таймкоды по всем сериям, на каком бы устройстве их ни смотрели. Позиция, записанная этим устройством позже (её отчёт может быть ещё в очереди), не затирается.

Работает с Online Mod и Showy (определение серии по таймлайну Lampa), остальные онлайн-плагины — по карточке и таймлайну.

## Установка

1. Запустить сервер (`kadr-sync-server/README.md`). Профиль можно создать заранее (`create-profile "Имя"`) или прямо при привязке (`pair КОД "Имя" --create`).
2. В Lampa: **Настройки → Расширения → Добавить плагин** → `https://kiriyk.github.io/plugins/sled/sled.js`, перезапустить Lampa.
3. **Настройки → Sled**: адрес сервера, затем **Привязать по коду**. На экране появится код вида `K7M-4QX`; на компьютере с сервером выполните `python -m kadr_sync.cli pair K7M-4QX "Имя профиля"` (в Docker — через `docker compose exec kadr-sync …`). Sled сам получит ключ устройства и подключится. Ключ можно и вставить вручную: **Ключ профиля → Сохранить профиль**. После — **Проверить связь**.
4. **Настройки → Плеер**: внешний плеер Android, KADR 0.2.1 или новее.

Ключ профиля хранится только в настройках Lampa на этом устройстве. KADR получает лишь токен одного просмотра.

Что учесть:
- Резервная копия настроек Lampa (CUB, экспорт) включает и ключи профилей Sled. Не передавайте такую копию другим. Если копия ушла, отзовите ключи профиля на сервере (`revoke-key "Имя"`, это отключит все его устройства) и привяжите устройства заново.
- Lampa пишет адрес видео в консоль отладки, а в этом адресе есть токен просмотра. Токен действует только для одного просмотра и только на запись его прогресса.

## Интерфейс

Все точки входа показывают одну историю активного профиля из локального кэша — и без сети тоже.

- **Главная → «Продолжить просмотр»** — по карточке на фильм или сериал: начатые и сериалы с досмотренной серией (предложит следующую). Встроенную строку Lampa с тем же названием можно выключить в настройках главной.
- **Боковое меню → «История»** — «Продолжить просмотр» или «Вся история» (каждая серия отдельно), страницами по 20.
- **Кнопка «Sled · S6E7 · 12:30 из 21:18»** в карточке фильма или сериала, если по нему есть история.
- **Отметки на постерах** — жёлтая полоса прогресса у начатого, галочка у просмотренного фильма.

Нажатие на запись открывает меню:

| Пункт | Что делает |
| --- | --- |
| Позиции разошлись — выбрать | есть, если два устройства продолжили одну позицию независимо: показывает обе позиции с устройством и временем, выбранная сохраняется на сервере |
| Продолжить с 12:30 | открывает сохранённый источник; после выбора серии старт на 10 с раньше |
| Следующая серия · S6E8 | для досмотренной серии; открывает источник, серия стартует с начала без вопроса |
| Сначала | то же, с 0:00 |
| Выбрать источник | открывает карточку; при запуске из любого источника Sled спросит «Продолжить / Сначала» |
| Отметить просмотренным / Снять отметку | статус синхронизируется на все устройства профиля |
| Удалить из истории | после подтверждения запись пропадает отовсюду |

Если изменения ещё не дошли до сервера, заголовки полки и истории получают «· ждёт синхронизации».

**Проверить связь** в настройках Sled показывает и то, какие точки входа подключились: `интерфейс: всё подключено` или `интерфейс: нет …` — если версия Lampa на устройстве их не поддерживает.

## Оценки

Своя оценка 1–10 и, по желанию, текст впечатлений для фильма или сериала целиком. Оценки хранятся на сервере истории, видны на всех устройствах профиля и работают без сети (отправятся позже). Нужен `kadr-sync-server` с поддержкой оценок; со старым сервером оценки копятся в очереди до его обновления.

- **После фильма.** Если фильм досмотрен (сервер отметил его просмотренным, порог профиля — по умолчанию 95%) и оценки ещё нет, Sled предлагает «Оценить «Название»?». «Не сейчас» или «Назад» закрывает окно, для этого фильма оно больше не появится. После серий окна нет: сериал оценивается в карточке.
- **Карточка фильма или сериала.** Кнопка «Оценить» или «★ 8». Меню: изменить оценку, «Впечатления», удалить оценку. Оценить можно и то, что не смотрели через KADR.
- **Впечатления** вводятся в обычном поле Lampa. С системной клавиатурой Android (выбирается в настройках Lampa) работает голосовой ввод её кнопкой микрофона. До 2000 символов.
- **Постеры.** «★ 8» вверху слева, рядом с отметками прогресса (снизу) и плагина рейтингов (внизу справа).
- **Боковое меню → «История» → «Мои оценки».** Всё оценённое, сначала новые.

Если оценку меняли на двух устройствах, остаётся последняя правка.
