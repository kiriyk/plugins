# КП + IMDb на постерах Lampa

Плагин для **Lampa 3.x**, разработан по исходникам **3.3.8**. Показывает на постерах каталога оценки **КП** и **IMDb** вместо исходной оценки TMDB/CUB.

- Есть обе оценки: два компактных бейджа справа внизу постера.
- Есть одна: один бейдж с подписью источника.
- Нет оценок или ошибка сети: исходная оценка остаётся. Это можно отключить в настройках.
- Нули, отсутствующие и некорректные значения не отображаются.
- На страницу фильма плагин не добавляет рейтинги.

## Что нужно

- **IMDb** работает без ключа. Оценки берутся из [Agregarr](https://agregarr.org/docs/imdb-ratings/), как в плагине ИИ-подборок. Это публичный бесплатный API на базе ежедневных некоммерческих наборов IMDb, без обещания неограниченной доступности.
- **КП** требует персональный ключ **[Kinopoisk API Unofficial](https://kinopoiskapiunofficial.tech/)**. Зарегистрируйтесь на сайте и скопируйте ключ из профиля. Это сторонний API, не официальный API Яндекса. Доступность и лимиты определяются сервисом. Ключ общий с плагином ИИ-подборок.

Если источник каталога уже передаёт оценки в данных карточки, плагин показывает их без запросов.

**В JavaScript-файл ключ вставлять не нужно.** Введите его в настройках Lampa после установки. Не загружайте личные ключи на GitHub.

## Размещение на GitHub Pages

1. Создайте публичный репозиторий, например `lampa-catalog-ratings`.
2. Распакуйте архив. Загрузите содержимое папки `lampa-catalog-ratings` в корень репозитория. Файл `catalog-ratings.js` должен находиться непосредственно в корне.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**. Сохраните.
5. Дождитесь публикации. Адрес плагина будет:

   ```text
   https://ВАШ-ЛОГИН.github.io/lampa-catalog-ratings/catalog-ratings.js
   ```

   Замените логин и название репозитория своими. Проверяйте именно опубликованный `.js`, а не страницу файла с `github.com/.../blob/...`.

Для запуска достаточно одного `catalog-ratings.js`. Node.js, npm, сборка и сервер для установки плагина не нужны. Остальные файлы предназначены для документации и разработки.

## Установка в Lampa

1. **Настройки → Расширения → Добавить плагин**. В некоторых сборках раздел называется «Плагины».
2. Вставьте адрес опубликованного `catalog-ratings.js`.
3. Полностью перезапустите Lampa.
4. Откройте **Настройки → Рейтинги на постерах**.
5. Вставьте **Ключ Kinopoisk API Unofficial**.
6. Нажмите **Проверить API**. При успехе появятся оценки контрольного фильма.
7. Вернитесь в каталог. Оценки подгружаются по мере появления постеров на экране.

## Как это работает

Плагин расширяет стандартный модуль карточек через `Lampa.Maker.map('Card').Card.onCreate`, сохраняя его исходный обработчик. Для каждой карточки использует события `onVisible`, `onUpdate`, `onDestroy`.

Для источников `tmdb` и `cub` IMDb ID сначала берётся через встроенный `Lampa.Api.sources.tmdb.external_ids`. Используется действующая конфигурация доступа к TMDB в Lampa.

**IMDb:** точные IMDb ID видимых карточек собираются в пакет (до 20 ID за 100 мс) и отправляются одним запросом `https://api.agregarr.org/api/ratings?id=...&id=...`. Квоту Кинопоиска это не тратит.

**КП** выполняется по точным идентификаторам:

1. Если есть `kinopoisk_id` / `kinopoiskId` / `kp_id`, запрос к `/api/v2.2/films/{id}`.
2. Если есть IMDb ID, запрос к `/api/v2.2/films?imdbId=...`.
3. Если IMDb ID нет или по нему фильм не найден, выполняется строгий поиск по названию: `/api/v2.2/films?keyword=...` с годом ±1. Оценка принимается, только если ровно один результат совпадает по точному названию (русскому, английскому или оригинальному), году ±1 и типу (фильм/сериал), а его IMDb ID не противоречит известному. При неоднозначном результате оценка не показывается, чтобы не смешивать одноимённые фильмы. Так появляются оценки КП у российских фильмов и сериалов, которых нет в IMDb.

Если в Agregarr оценки IMDb нет, используется оценка IMDb из ответа Кинопоиска.

Для нестандартных источников можно передать `tmdb_id`, IMDb ID или ID Кинопоиска. Произвольный `id` неизвестного источника не считается TMDB ID.

**Данные из карточки:** поддерживаются явные поля `ratingKinopoisk`, `rating_kp`, `kp_rating`, `kinopoisk_rating`, `rating.kp` и `ratingImdb`, `rating_imdb`, `imdb_rating`, `rating.imdb`. `vote_average` не выдаётся за оценку КП или IMDb.

### Нагрузка и кэш

- До четырёх одновременных заданий на получение оценок.
- Повторные постеры одного фильма используют один запрос.
- Кэш раздельный: КП хранится 30 дней, IMDb 7 дней, отсутствие оценки 12 часов. Максимум 500 фильмов. Уже известная оценка КП не запрашивается повторно, даже если устарела IMDb.
- Один фильм расходует не больше одного запроса КП на 30 дней (плюс один запрос поиска, если по IMDb ID фильм не найден).
- Ошибки сети и TMDB не сохраняются как отсутствие рейтинга. Видимая карточка сама повторяет запрос через минуту, до трёх попыток.
- Ошибки Кинопоиска не останавливают IMDb.
- HTTP 401/403 от Кинопоиска приостанавливает запросы КП до изменения настроек или успешной проверки API.
- HTTP 429 приостанавливает запросы КП на минуту, затем отложенные карточки запрашиваются заново.
- HTTP 402 (исчерпан дневной лимит) приостанавливает запросы КП на час и показывает одно уведомление.
- Ответы для закрытых карточек или старого ключа не меняют интерфейс.

Первый просмотр новых каталогов всё равно расходует квоту Кинопоиска. Проверка ключа также выполняет один запрос.

## Если не заработало

- **Раздела настроек нет:** проверьте адрес `.js`, включение расширения и перезапуск. Версия ядра должна быть 3.x со стандартным модулем карточек.
- **Ошибка 401/403:** проверьте ключ, его статус и остаток лимита в профиле API.
- **Ошибка 429:** дождитесь окончания ограничения сервиса.
- **Исчерпан лимит запросов (402):** дневная квота ключа закончилась. Новые постеры показывают только IMDb, уже полученные оценки КП берутся из кэша.
- **Сеть / CORS / таймаут:** проверьте доступ к API на устройстве. Веб-движки телевизоров, сертификаты и сетевые ограничения отличаются. Плагин не включает сторонние CORS-прокси.
- **Проверка API успешна, но некоторые оценки не появляются:** для карточки может отсутствовать IMDb ID или соответствие в базе API; также проверьте доступ самой Lampa к TMDB.
- **Двойные или перекрывающиеся бейджи:** на время первой проверки отключите другие плагины, меняющие рейтинги и оформление постеров.
- **После обновления виден старый код:** поменяйте адрес расширения на `.../catalog-ratings.js?v=2` и перезапустите приложение.

## Проверка и ограничения

В комплекте 28 автоматических тестов в DOM-среде LinkeDOM с имитацией контрактов Lampa 3.3.8. Они проверяют вывод оценок, точные ID, кэш, очередь, закрытие карточек, ошибки ключа, ограничение частоты запросов, таймаут и смену ключа, автоповтор, поиск по названию, лимит 402 и пакетные запросы IMDb. Acorn проверяет синтаксис ES5.

Тесты не обращаются к настоящему API. Прямой запрос с вашим ключом и работу на физическом телевизоре нужно проверить после установки. Совместимость со всеми темами, сборками и будущими версиями Lampa не гарантируется.

Для разработки нужен Node.js 20+:

```bash
npm ci
npm test
npm run check
```

Документация источника оценок: https://kinopoiskapiunofficial.tech/documentation/api/
