# KADR Probe

Временный диагностический плагин для этапа 0 интеграции KADR и Lampa. Не нужен для обычного использования.

Записывает в журнал (последние 30 записей) данные запуска плеера, плейлист и возврат таймкода. Полные URL, query-строки и значения заголовков **не сохраняются**: остаются схема и хост, длина пути и длина значения.

## Установка

Вариант 1 — GitHub Pages этого репозитория: `https://<логин>.github.io/<репозиторий>/kadr-probe/kadr-probe.js`.

Вариант 2 — локально в той же сети: на компьютере выполнить `python3 -m http.server 8000` в корне репозитория и добавить в Lampa `http://<IP компьютера>:8000/kadr-probe/kadr-probe.js`.

**Настройки → Расширения → Добавить плагин**, затем полностью перезапустить Lampa.

## Использование

- **Настройки → KADR Probe → Показать журнал**: просмотр записей.
- **Передавать тестовый заголовок**: добавляет `X-Kadr-Probe` со случайной меткой при запуске во внешнем плеере Android. Ту же метку должна показать диагностика KADR 0.1.2.
- Журнал также выводится в консоль (`chrome://inspect` при включённой отладке WebView).

После завершения проверок удалите плагин.
